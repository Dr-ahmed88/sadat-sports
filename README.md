# بوابة المواهب الرياضية — جامعة مدينة السادات

نسخة تجريبية لحصر المواهب الرياضية للطلاب (أولمبياد الجامعات المصرية 54 — 2026/2027).

## الملفات
- `index.html` الصفحة الرئيسية
- `css/style.css` التصميم
- `js/app.js` المنطق (الاستمارة، لوحة الإدارة، التصدير)
- `assets/` الشعار وصورة الهيدر

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub، ويفضل أن يكون **Private** أثناء التجربة.
2. ارفع محتويات المجلد (وليس المجلد نفسه) عبر **Add file → Upload files**، ثم **Commit changes**.
3. من **Settings → Pages**: اختر Source = `Deploy from a branch`، والفرع `main`، والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

> ملاحظة: GitHub Pages في الحسابات المجانية يتطلب مستودعًا عامًا (Public).

## حدود النسخة الحالية
البيانات تُحفظ في متصفح كل جهاز فقط (`localStorage`)، فلا يراها أحد غيرك. لا تطلب من الطلاب تعبئتها قبل ربط قاعدة بيانات وتسجيل دخول حقيقي.
